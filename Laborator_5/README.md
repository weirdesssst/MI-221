# Varianta 7
Creați un program care citește și afișează jurnalele de sistem (de exemplu, jurnalele de pornire 
ale sistemului sau erorile) și adăugați execuția acestor funcții la intervale regulate (folosiți 
Planificatorul de sarcini în Windows):
• Pentru Linux: citiți jurnalele din /var/log/syslog sau /var/log/messages.
• Pentru Windows: folosiți comanda wevtutil pentru a citi jurnalele.
